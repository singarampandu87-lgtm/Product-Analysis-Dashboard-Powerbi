# Product Analysis Dashboard (Power BI)

## Project Overview

This project is an interactive Product Analysis Dashboard developed using Microsoft Power BI.

The dashboard helps analyze sales performance, product categories, regional performance, discounts, and order trends.

--## Tools Used

- Microsoft Power BI
- Microsoft Excel / CSV
- Data Visualization
- Data Cleaning

## Dashboard Features

- Region Filter
- Category Filter
- Sub-Category Filter
- State Filter
- Sales Trend Analysis
- Decomposition Tree
- Average Discount by Category
- Quantity Analysis
- State-wise Quantity Distribution
